## 口径

- **过短%**：块长 < 200 字的比例
- **跨章节%**：一个块覆盖 2 个以上章节的比例（结构感知按定义为 0）
- **表格破损%**：块里出现竖线行但没有完整「表头+分隔行」的比例
- **代码破损%**：块里 ``` 围栏数不配对的比例
